**MN Ink** 是一个 MarginNote 4 插件：把 Notability / GoodNotes 那样的书写体验带进 MarginNote——压感笔刷、画完按住自动规整图形、根号自动整齐、GoodNotes 式套索、局部橡皮擦、格子纸、激光笔，**脑图和 PDF 页面都能写**。

笔迹是矢量的，直接画在 MarginNote 自己的脑图画布和 PDF 内容层里，跟着一起滚动、缩放，放大也清晰；**数据存在笔记本里**，所以 MarginNote 的备份、iCloud 同步、导出和 ⌘Z 撤销都天然覆盖它。

## ✨ 功能

| | |
| --- | --- |
| ✒️ **笔刷** | 普通、等宽、钢笔、毛笔、铅笔、**水彩**、**蜡笔**；像 MN 一样可以**复制出任意多支笔**；每支笔单独设**不透明度**、**脑图 / PDF 分开的粗细**、**直线（关 / 自动 / 始终）**、**消失模式**、**完美图形**；压感灵敏度 0–100% |
| 📏 **尺子** | 拖动、旋转（15° 吸附），贴着尺子边画出笔直的线 |
| 🗂 **图层** | 新建、重命名、隐藏、删除；书写和擦除只作用于当前图层 |
| 🖐 **手 / 手势** | 拖动画布；双击卡片聚焦；双指轻点撤销、三指轻点重做；**防手掌误触**（手掌搭在屏幕上不会拖动画面、不会误撤销） |
| 🖍 **荧光笔** | 半透明、永远在字下面；可开「自动拉直」，或画完按住拉直 |
| 📐 **图形** | 画完按住半秒 → 规整成直线、箭头、**圆弧**（两端吸附、弦自动拉正）、圆、椭圆、矩形、三角形、多边形、折线；**按住后继续拖动可微调**（改长度方向、大小、弧长）；图形工具下每笔自动识别，支持虚线辅助线 |
| √ **根号** | 写完自动变成规整的根号（按作者本人的手写习惯校准），拖动可拉长横线 |
| 🧲 **吸附** | 端点 / 角点吸附到其他图形的节点和格点；直线 15° 角度吸附，接近水平竖直自动拉正 |
| ⭕ **套索（GoodNotes 式）** | **碰到笔迹的任何一点就选中**；手绘套索 / 矩形框选；按类型筛选（手写 / 荧光笔 / 图形）；移动、缩放、**旋转**、改颜色、拷贝、剪切、粘贴、再制、删除、**转为卡片**、**绑定到卡片**；单个图形可直接拖**节点** |
| 🩹 **橡皮擦** | 整笔擦除 / 局部擦除（把笔画切开）；只擦荧光笔；擦完自动切回；**涂抹擦除**（像 GoodNotes：用笔在字上来回涂抹，连同涂抹线一起擦掉） |
| 🎨 **颜色** | 常用色 + 最近使用 + 28 色调色板 + **16 进制输入** + 系统取色器 + **吸管**（从已有笔迹取色） |
| 🔴 **激光笔** | 演示用的发光轨迹，松手后自动消失，不留痕迹 |
| 🗒 **书写背景** | 方格 / 点阵 / 横线，三档大小，只在书写时显示 |
| 📄 **PDF 页面** | 在文档上直接写，笔迹跟着页面走；脑图和 PDF 同屏时可一键切换书写对象 |

## 🔗 与 MarginNote 深度融合

- **接管自带的书写按钮**：MarginNote 自己的笔（脑图右侧工具栏、PDF 工具栏）变成 MN Ink 的开关，按钮高亮跟着 MN Ink 走，不会再进入 MarginNote 的书写模式（不跳画面、不出它的背景）。可在设置里关闭。
- **需要改以前用 MarginNote 自带笔写的字**：设置 → 「暂时用 MN 自带笔」，用完退出 MarginNote 的书写模式后自动恢复接管。
- **存在笔记本里**：每个笔记本有一张隐藏的「笔迹存储」笔记（和 MarginNote 自己的 AI 对话、手写图层一样不显示在脑图上），每张卡片 / 每个 PDF 页面一条记录。所以：
  - **MarginNote 的备份、iCloud 同步、.marginpkg 导出都包含笔迹**，换设备也在；
  - **每一笔都是 MarginNote 撤销历史里的一步**：工具条上的撤销就是 MarginNote 的撤销，用菜单或 ⌘Z 撤销也会立刻反映到笔迹上。
- **笔迹跟着卡片走**：脑图上的笔迹挂在最近的卡片上，卡片移动、分支折叠时一起移动 / 隐藏。

## 🚀 安装

1. MarginNote → 设置 → Extension → 打开 **Allow uncertified extensions**（iPad 上同样要开）。
2. 下载 [`MNInk.mnaddon`](https://github.com/Jacky1n7/mn-ink/releases/latest/download/MNInk.mnaddon)，用 MarginNote 打开（Mac 双击；iPad 用隔空投送 / 文件 App 选 MarginNote），按提示重启。
3. 打开笔记本，点插件栏里的笔形图标（或直接点 MarginNote 自己的笔），开始书写；「完成」退出。

## ✍️ 用法速查

- **再点一次当前工具** → 打开它的设置（笔型、压感、线型、擦除方式、套索方式……）。
- **再点一次当前颜色 / 粗细** → 调色板 / 粗细滑块。
- **画完别抬笔，停半秒** → 规整图形；**接着拖** → 微调。
- **手指**：单指平移、双指缩放（只有 Apple Pencil 会落笔，手掌不会误画）。Mac 触控板双指滑动平移、捏合缩放。
- 工具条左边的 ⋮⋮ 把工具条移到顶部 / 底部。
- 快捷键（Mac）：P 笔 · H 荧光笔 · S 图形 · E 橡皮 · L 套索 · K 激光笔 · G 背景 · ⌘Z / ⇧⌘Z · ⌘C / ⌘X / ⌘V / ⌘D · Delete · Esc。

## ⚙️ 原理

```
Apple Pencil ─▶ 透明书写层（WebView：压感、合并事件、预测点、实时笔画、图形识别）
                     │ mnink://… 消息（逐批确认，不丢包）
                     ▼
              MN Ink 插件（JSB）──▶ CAShapeLayer 画进 MindMapCanvas / PDF 内容层
                     │
                     └──▶ 隐藏的「笔迹存储」笔记（UndoManager.undoGrouping → MarginNote 撤销 / 备份 / 同步）
```

- 笔画轮廓用 [perfect-freehand](https://github.com/steveruizok/perfect-freehand) 生成，书写层和原生渲染用同一套参数，所见即所得。
- 脑图笔迹以卡片为锚点；PDF 笔迹以页面片段为锚点，坐标按页宽归一化，缩放后重新绘制保持清晰。
- 插件无法直接设置笔记的「隐藏」标记，所以存储笔记是克隆一张已有的隐藏笔记得来的。

## ⚠️ 已知限制

- **Apple Pencil 双击切换橡皮做不到**：MarginNote 不给插件开放 Pencil 双击（UIPencilInteraction）。可以用涂抹擦除代替。
- MarginNote 自带笔写的字是 PencilKit 笔迹，插件读不到，MN Ink 的橡皮和套索动不了它们（用「暂时用 MN 自带笔」去改）。
- 存储笔记会出现在 MarginNote 的 **AI 对话历史**里，标题是「✒️ MN Ink 手写笔迹存储（请勿删除）」。误删后可以 ⌘Z 撤销；插件也会用内存中的笔迹自动重建。
- 笔记本里一张隐藏笔记都没有时（从没用过 AI 对话或手写），会先把笔迹存在本机文件里，之后自动迁入笔记本。
- PDF 只支持纵向滚动的阅读模式；PDF 的缩放请用 MarginNote 自己的手势。
- 用的是 MarginNote 未公开的视图结构（4.4.6 实测），MarginNote 大版本更新后可能需要适配。

## 🛠 开发

```bash
npm test                       # 图形识别 + 存储层单测 + 无头 Chrome 页面交互测试
npm run build                  # 发布版 → dist/MNInk-v<版本>.mnaddon
npm run build:dev              # 开发版：带热更新通道（不要分发）
node scripts/dev.mjs push      # 不重启 MarginNote，热更新全部代码和页面
node scripts/dev.mjs eval '<js>'
node scripts/make-banner.mjs   # 用真实笔刷算法生成 README 首图
```

会让 MarginNote 直接崩溃（无法 try/catch）的调用记录在 `addon/src/40-render.js` 文件头。开发版的热更新通道经 [MN Agent Bridge](https://github.com/Jacky1n7/marginnote-agent-bridge) 的回执程序返回结果。
